# rclone-erik

Personal Google Drive OAuth configuration for [rclone](https://rclone.org/), operated by Erik (GitHub: [traikdude](https://github.com/traikdude)). This is a personal configuration of the independent rclone application, not an official rclone service.

This configuration uses a dedicated Google OAuth Desktop app client named **rclone**, with Google Cloud project ID **rclone-erik-20261013**. Its purpose is to let the account owner list and download their own Google Drive files through rclone on their Windows computer.

## Permissions

The requested permission is `https://www.googleapis.com/auth/drive.readonly`: see and download Google Drive files. This configuration does not request permission to upload, edit, rename, or delete Drive files.
